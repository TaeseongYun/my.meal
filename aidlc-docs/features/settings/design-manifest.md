## 항목 구성 (2026-09-09 재정의 — 목업 플레이스홀더 대체)

deep-research 조사(2026-09-09, 스토어 정책·국내 법령 1차 출처)로 실제 항목을 확정했다:

- **계정** — 로그아웃 / 회원 탈퇴 (alertRed)

근거와 분류:
| 항목 | 등급 | 근거 |
|------|------|------|
| 개인정보 처리방침 | **출시 차단** | Apple 5.1.1(i) "within the app in an easily accessible manner" + Play User Data + 개인정보 보호법 §30② (§75④8, 과태료 1천만원 이하) |
| 회원 탈퇴(계정+연결 데이터 삭제) | **출시 차단** | Apple 5.1.1(v) + Play data deletion. 로그아웃·휴면 대체 불가. Supabase `auth.users`만 삭제하면 미달 — 기록 행 + Storage 객체 cascade 필요, service_role 키를 클라이언트에 못 실으므로 Edge Function 경유 |
| 웹 계정삭제 요청 URL | **출시 차단(앱 밖)** | Play Console Data safety 폼 제출물. Apple 불요. 미제출 시 업데이트 제출 차단 |

## 구현 메모
- 항목 재정의로 스위치 행이 사라져 M3 `Switch`는 쓰지 않는다. 트레일링은 셰브런 / 버전 텍스트 / 로그아웃 아이콘 3종.
- 섹션 헤더는 목업의 기어+라벨 패턴을 유지하되 아이콘만 교체(정보 = ⓘ, 계정 = 사람). 기어는 미사용이라 삭제.
- 아이콘은 home/record와 같은 Canvas 근사. 기어·연필은 home의 상단바 아이콘과 같은 형태를
  크기 비례로 다시 그렸다(feature 간 직접 의존 금지). **아이콘 3종 이상이 중복된 시점 —
  `:core:designsystem` 승격 후보**로 기록한다.
