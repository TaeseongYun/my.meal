## 확정 필요 항목 (스텁 결정)
- 아침/점심 라벨 이모지: 홈 디자인엔 "🌑 저녁"만 존재. 생성하기 프레임 렌더 판독으로 ☀️ 아침 / ⛅ 점심 추정 적용 — 디자이너 확인 필요
- "{N}월 {몇}째주" 규칙: 디자인 샘플(6월 둘째주)로는 역산 불가 — 주의 목요일이 속한 달·주차로 구현, 디자이너 확인 필요
- 글귀 스텁: 디자인의 한글 입숨 3줄 전사 (FAB에 가린 꼬리는 근사 복원)
- 캘린더 스텁 기록: 오늘 이전 3일에 🥗🍚🍞 (디자인 샘플 동일) — 이번주 밖이면 표시되지 않음 (정상)
